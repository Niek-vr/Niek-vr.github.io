Wanneer is HTML bedacht?

HTML is bedacht door Tim Berners-Lee in 1991. Hij werkte bij CERN, een onderzoekscentrum in Zwitserland. Hij bedacht HTML om informatie en documenten via het internet met elkaar te kunnen verbinden.
HTML maakte het mogelijk om webpagina's te maken met teksten en links, zodat mensen makkelijk van de ene pagina naar de andere konden gaan.

Waarvoor wordt het gebruikt?

HTML staat voor HyperText Markup Language. Het is een taal waarmee je websites maakt. De maker schrijft HTML-code op een computer. Daarna opent een browser, zoals Google Chrome, de code en laat deze zien als een website.
HTML wordt bijvoorbeeld gebruikt voor:
- Titels en teksten op een website.
- Afbeeldingen toevoegen.
- Links maken naar andere webpagina's.
- Lijsten en tabellen maken.
Tegenwoordig wordt HTML gebruikt voor bijna alle websites, zoals webshops, nieuwssites en websites van scholen.
